# Construction Web Terra（C-WEB）

外仕事をする一人親方・小規模施工店向けの、スマホ運用を前提にしたホームページ制作サービスサイトです。既存のEXた組関連サイトとは完全に分離しています。

## 確認方法

`index.html` をブラウザで直接開くか、このディレクトリで次を実行してください。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## ビルド

```bash
npm run build
```

検証済みの公開用ファイルが `dist/` に生成されます。

## 初期版に含むもの

- レスポンシブ対応トップページ
- 実画像6枚によるデザイン方向（スマホ横スワイプ・タップ拡大）
- 税込198,000円の先着3社限定・導入価格
- 標準5ページ、初期写真20枚、修正2回の標準仕様
- ドラッグ並び替え・公開切替ができるスマホ更新UIデモ
- 制作の流れ、運営者紹介、FAQ、問い合わせ導線

## 更新機能の実装段階

- Next.js / TypeScriptへの移行
- Supabase Authによる施工店別ログイン
- Supabase Storageへの複数画像アップロード
- 施工事例データ、カテゴリ、公開状態、並び順の永続化
- 顧客別の更新機能は外部サービス、保存容量、契約主体を見積時に確定
- 問い合わせ受信後の `generate_lead` オフライン計測連携
