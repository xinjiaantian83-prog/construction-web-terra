# Construction Web Terra（C-WEB）

外仕事をする一人親方・小規模施工店向けの、スマホ運用を前提にしたホームページ制作サービスサイトです。既存のEXた組関連サイトとは完全に分離しています。

## 確認方法

`index.html` をブラウザで直接開くか、このディレクトリで次を実行してください。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## ビルド

```bash
npm run build
```

検証済みの公開用ファイルが `dist/` に生成されます。

## 初期版に含むもの

- レスポンシブ対応トップページ
- 実画像6枚によるデザイン方向（スマホ横スワイプ・タップ拡大）
- 通常価格とEXた組登録施工店価格
- 制作品質維持のための月8件受付表示
- ドラッグ並び替え・公開切替ができるスマホ更新UIデモ
- 制作の流れ、運営者紹介、FAQ、問い合わせ導線
